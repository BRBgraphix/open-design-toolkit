# Project Plan

## Vision

Make common design-asset preparation tasks easier with a free, approachable desktop utility.

## Version 0.1.0

- [x] Basic PNG/JPEG optimization
- [x] Batch rename preview
- [x] Safe output folder for optimized images
- [x] Initial automated tests

## Next priorities

1. Test on Windows 10 and Windows 11.
2. Improve error messages and progress feedback.
3. Add SVG metadata inspection (without changing SVG contents).
4. Add packaging documentation.
5. Gather feedback from real users before expanding scope.

## Maintainer checklist

- Review every issue and pull request.
- Reproduce reported bugs before fixing them.
- Run tests before each release.
- Document user-visible changes.
- Never publish client artwork or private files without permission.
